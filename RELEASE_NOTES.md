# mk-piclock v1.9.14-rpi-zero-r3 Release Notes

This release restores sent-message artwork to the normal clock image size and gives message text a smaller, independent layout.

## Full-size message artwork

- Message artwork uses the normal 96x48 clock viewport.
- The artwork begins at X=2, matching the first pixel of the `ALARM` footer text.
- The 2:1 artwork ratio is preserved without compressing the image into a smaller thumbnail.
- Image-only messages use the same 96x48 viewport.

## Compact message text

- Message text uses an independent 9px to 12px TrueType font range.
- The built-in fallback font uses scale 1 instead of scale 2.
- Text is restricted to a 144x48 viewport at X=106, Y=8.
- The renderer validates both width and height before accepting a message.
- The browser preview is generated by the same framebuffer renderer used by the physical OLED, so both layouts match exactly.
- Daytime and bedtime image-library previews remain unchanged.

## Compatibility

- Product version: `1.9.14-rpi-zero-r3`
- HTTP API version: `1.26`
- Private IPC version: `16`
- Target hardware: Raspberry Pi Zero W and Raspberry Pi Zero 2 W
